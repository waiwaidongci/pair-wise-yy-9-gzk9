# 古法蓝晒底片整理室

运行：

```bash
npm start
```

访问`http://localhost:3040`。数据保存在`data/cyanotype-negative-room.json`。

## 数字化交付

访问 `http://localhost:3040/scans`。扫描单登记底片编号、设备、工位、校准日期、目标分辨率和扫描人；校准过期（超过365天）或分辨率低于1200的单留在待复扫、不占工位。同一底片和同一工位各自只能有一张未完成单；交付需填写文件数、校验码和复核人，复核人与扫描人相同会被退回；底片编号或设备更换后原交付失效。业务规则在 `rules.js`，记录保存在 `store.js`，页面与接口在 `server.js`。
